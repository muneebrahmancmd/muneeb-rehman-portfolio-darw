## About

A personal portfolio website for Muneeb Rehman, built as a fast, animated, pure static site. No framework, no build step — just open it and it runs.

## Features

- Smooth scrolling with Locomotive Scroll
- GSAP-powered animations with ScrollTrigger
- Text splitting effects
- Animated preloader
- Dark and light themes
- Accordion sections
- Responsive layout

## Tech Stack

- HTML
- CSS / SCSS
- JavaScript
- GSAP + ScrollTrigger
- Locomotive Scroll
- Bootstrap
- Font Awesome

## Run Locally

No build step needed. Clone the repo and open `index.html` in a browser, or serve the folder with any static server:

```bash
git clone https://github.com/muneebrahmancmd/muneeb-rehman-portfolio-darw.git
cd muneeb-rehman-portfolio-darw
```

Then open `index.html`.
